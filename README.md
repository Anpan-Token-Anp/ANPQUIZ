# 🎮 Manga Quiz Airdrop

Un site de quiz sur les mangas légendaires des années 90 à aujourd'hui. Les utilisateurs répondent à 7 questions et reçoivent des tokens crypto en récompense selon leurs résultats.

## 🚀 Fonctionnalités

- Quiz interactif avec questions issues de l'API OpenTDB
- Interface animée avec effet glass, dégradés violet/rouge
- Connexion Metamask pour recevoir des récompenses en token
- 1 token pour les participants / 10 tokens pour les gagnants (5 bonnes réponses ou plus)
- Classement en temps réel des scores
- Multilingue prévu (anglais par défaut)

## 🧩 Technologies utilisées

- HTML, CSS, JavaScript (Vanilla)
- Thirdweb SDK pour l’envoi de tokens
- OpenTDB API (catégorie Anime & Manga)
- GitHub Pages pour l’hébergement
